# Pitch materials: reading order

For judges. The deck's script names each slide's sources, mostly claim ids (`C35`) from the claims ledger; the
Saturday outline and speaker notes tag every sentence the same way.

1. [motion/README.md](motion/README.md): the 3-minute deck (offline `index.html`, `deck.pptx` fallback) and its script.
2. [story.md](story.md): the story in five acts, each number with its source.
3. [claims.md](claims.md): the claims ledger; each row is labelled REAL, SIMULATED, UNVERIFIED or PENDING.
4. [evidence.md](evidence.md): the commands that capture the evidence behind the claims.
5. [demo.md](demo.md): the live demo plan and its backups (Bazaar Live, Phoenix replay).
6. [qa.md](qa.md): likely judge questions, each answered in 20 seconds with a number or a file.
7. [charts/charts.md](charts/charts.md): data specs for the charts; the CSV files sit next to it.

Earlier drafts: [outline.md](outline.md) (7-minute outline), [script.md](script.md) (speaker notes, ES + EN),
[demo-inventory.md](demo-inventory.md) (asset inventory). Most files here were drafted on Saturday 3 Oct; where they
differ from the deck, the deck is the later version.
